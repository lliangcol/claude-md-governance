# Launch Plan

This plan keeps the first launch focused on conversion and installation trust,
not feature expansion.

## Manual GitHub Setup

- Topics: `claude-code`, `claude-md`, `policy-as-code`, `ai-agents`, `governance`, `hooks`, `ci`.
- Social preview: upload `docs/assets/social-preview.png`.
- About description: `Make Claude Code repo rules enforceable with policy-as-code, hooks, and CI.`
- Pin the repository after `v0.1.0` release artifacts are visible.

## Starter Issue Titles

- `Preset request: <ecosystem>`
- `Rule request: protect <path/tool>`
- `Docs: add demo for <workflow>`
- `CI provider request: <provider>`

## Six-Week Launch Loop

| Week | Theme | Deliverable | CTA |
| --- | --- | --- | --- |
| 1 | Repository conversion | README, release, demo, topics, social preview | Try the demo in 3 minutes |
| 2 | First announcement | X thread, Dev.to tutorial, Chinese long-form post | Run it on a repo |
| 3 | Failure proof | Bad repo interception demo | Share a broken CLAUDE.md case |
| 4 | Positioning | "Why CLAUDE.md alone is not enough" comparison | Request a rule |
| 5 | Case study | Real or anonymized adoption story | Request a preset |
| 6 | Follow-up release | `v0.1.x` changelog and feedback recap | Upgrade and report gaps |
