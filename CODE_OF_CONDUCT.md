# Code of Conduct

We follow a simple standard: be respectful, practical, and evidence-driven.

## Expected behavior

- Assume good intent.
- Explain tradeoffs clearly.
- Prefer reproducible examples over opinions.
- Keep discussions focused on tool quality and user safety.

## Unacceptable behavior

- Harassment or personal attacks.
- Publishing private repository data or credentials.
- Encouraging unsafe hook scripts that run destructive commands by default.
- Misrepresenting test results.

Report concerns through the project's security or maintainer contact once the public repository is created.
